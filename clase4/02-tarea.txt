**Objetivo:** practicar la resolución de problemas utilizando funciones, condicionales, ciclos y listas.

**Instrucciones:**
- Resolver los ejercicios utilizando Python.

## Ejercicio 1. Clasificar temperaturas

Crear una función llamada `clasificar_temperatura(temperatura)` que reciba una temperatura y devuelva:

- `"Frío"` si es menor a 15.
- `"Templado"` si está entre 15 y 25, inclusive.
- `"Caluroso"` si es mayor a 25.

Probar con los siguientes valores:

```python
print(clasificar_temperatura(10))
print(clasificar_temperatura(20))
print(clasificar_temperatura(30))
```

## Ejercicio 2. Calcular descuentos

Crear una función llamada `calcular_precio(precio, descuento)` que reciba el precio original y el porcentaje de descuento, y devuelva el precio final.

Ejemplo: si un producto cuesta $20.000 y tiene un descuento del 10 %, el precio final será $18.000.

Probar con:

```python
print(calcular_precio(20000, 10))
print(calcular_precio(5000, 20))
print(calcular_precio(10000, 0))
```

## Ejercicio 3. Contar números positivos

Crear una función llamada `contar_positivos(numeros)` que reciba una lista y devuelva cuántos números son mayores que cero.

Probar con:

```python
print(contar_positivos([5, -2, 8, 0, -4, 3]))
print(contar_positivos([-1, -5, -8]))
print(contar_positivos([10, 20, 30]))
```

## Ejercicio 4. Buscar un nombre

Crear una función llamada `buscar_nombre(nombres, nombre_buscado)` que reciba una lista de nombres y un nombre para buscar.

La función debe devolver `True` si el nombre está en la lista y `False` si no está.

Probar con:

```python
nombres = ["Ana", "Lucas", "Martina", "Pedro"]

print(buscar_nombre(nombres, "Lucas"))
print(buscar_nombre(nombres, "Sofia"))
```

## Ejercicio 5. Calcular el total de una compra

Crear una función llamada `calcular_total(precios)` que reciba una lista de precios y devuelva la suma de todos ellos.

No utilizar la función `sum()`.

Probar con:

```python
print(calcular_total([1500, 2500, 3000]))
print(calcular_total([10000, 5000]))
print(calcular_total([]))
```

## Ejercicio 6. Filtrar números pares

Crear una función llamada `obtener_pares(numeros)` que reciba una lista y devuelva una nueva lista que contenga solamente los números pares.

Probar con:

```python
print(obtener_pares([1, 2, 3, 4, 5, 6]))
print(obtener_pares([1, 3, 5, 7]))
print(obtener_pares([10, 20, 30]))
```

## Ejercicio 7. Analizar notas

Crear una función llamada `analizar_notas(notas)` que reciba una lista de calificaciones y devuelva un diccionario con estos datos:

- `"aprobados"`: cantidad de notas mayores o iguales a 6.
- `"desaprobados"`: cantidad de notas menores a 6.

Probar con:

```python
print(analizar_notas([8, 4, 7, 5, 10, 6]))
print(analizar_notas([3, 2, 5]))
```

## Ejercicio 8. Generar una tabla de multiplicar

Crear una función llamada `tabla_multiplicar(numero)` que devuelva una lista con los primeros 10 resultados de multiplicar ese número por los números del 1 al 10.

Probar con:

```python
print(tabla_multiplicar(5))
print(tabla_multiplicar(7))
```

El resultado para el número 5 debería ser:

```python
[5, 10, 15, 20, 25, 30, 35, 40, 45, 50]
```

## Ejercicio 9. Encontrar palabras largas

Crear una función llamada `palabras_largas(palabras)` que reciba una lista de palabras y devuelva una nueva lista con aquellas que tengan más de 5 caracteres.

Probar con:

```python
print(palabras_largas(["casa", "computadora", "sol", "python", "mesa"]))
print(palabras_largas(["perro", "gato", "pez"]))
```

## Ejercicio 10. Sistema de puntos

Un jugador tiene una cantidad inicial de puntos y gana o pierde puntos en distintas rondas.

Crear una función llamada `calcular_puntos(puntos_iniciales, cambios)` que reciba los puntos iniciales y una lista con los cambios de cada ronda. La función debe devolver el puntaje final, sin permitir que sea negativo.

Si el puntaje llega a ser menor que cero, debe establecerse en cero.

Probar con:

```python
print(calcular_puntos(100, [20, -30, 10]))
print(calcular_puntos(50, [-20, -40, 30]))
print(calcular_puntos(0, [-10, 15]))
```
